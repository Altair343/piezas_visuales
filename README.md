# piezas_visuales

## Comandos:
npm run dev

npx canvas-sketch-cli src/sketch.js --open

npx canvas-sketch-cli src/sketch.js --open --output=./tmp/

npx canvas-sketch-cli src/sketch.js --new --open


canvas-sketch src/sketch.js --output=tmp --stream
